# Trezzo Auctions

Production-oriented Angular auction module for the Trezzo SaaS ecosystem.

## Features

- Realtime bidding
- Auction feed
- Auction detail pages
- Bid system
- Marketplace integration
- Angular + TypeScript architecture
- Component-based frontend structure
- REST API communication
- Responsive UI

## Tech Stack

- Angular
- TypeScript
- SCSS
- REST API
- Realtime systems

## Project Structure

- auction-feed
- auction-detail
- auction-card
- auction-create-editor
- bid-form
- auction services

## Purpose

This project is part of the Trezzo ecosystem — a multi-layer SaaS platform combining marketplace systems, messaging, creator tools and realtime communication.
